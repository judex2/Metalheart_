# Music Files Directory

Place your custom BGM track files here with the exact filenames listed below so the game can play them:

1. **Menu Theme**: `menu_theme.mp3`
2. **Battle Theme 1**: `battle_theme_1.mp3`
3. **Battle Theme 2**: `battle_theme_2.mp3`

The game uses standard HTML5 Audio to stream these files. If you don't place them here, the game will still run without errors and fail silently, but placing these tracks here will enable the dynamic, cross-faded musical landscape!
